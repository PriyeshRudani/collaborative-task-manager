# Collaborative Task Manager

A full-stack web application that enables users to manage tasks collaboratively with authentication, team features, and analytics.

---

## 🗺️ Project Overview

This application allows users to:

* 🪪 Register and log in securely
* 📌 Create and manage tasks
* 🤝 Collaborate with team members
* 📈 Track progress using analytics

---

## 🧰 Tech Stack

### 🖼️ Frontend

* React
* React Router
* Axios

### 🧪 Backend

* Node.js
* Express.js

### 🧱 Database

* MongoDB

### 🔏 Authentication

* JWT (JSON Web Token)

## 🛫 Getting Started

### 1️⃣ Clone the repository

```id="52d94h"

cd collaborative-task-manager
```

### 2️⃣ Setup Backend

```id="xsdgmx"
cd server
npm install
npm run dev
```

### 3️⃣ Setup Frontend

```id="6p50ko"
cd client
npm install
npm start
```
